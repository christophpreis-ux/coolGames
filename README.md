# coolGames

Eine Sammlung kleiner Browser-Spiele.

## Spiele

- [`minimap-racer`](./minimap-racer/README.md) – 2D-Rennspiel, bei dem das gesamte Spielfeld die Minimap ist. Fahr mit deinem schrottigen Einkaufswagen-Racer, biege an Kreuzungen im richtigen Moment ab und hol dir Diamant, Gold oder Silber.
- [`fishing-game`](./fishing-game/README.md) – Angel-Reaktionsspiel: Wirf aus, warte auf den Biss und drück die Tastenfolge (←↑↓→) nach, bevor die Zeit abläuft. Je länger die Folge, desto größer der Fisch und desto mehr Punkte.
- [`voltgarage`](./voltgarage/README.md) – Sammelkarten-Rennspiel: Öffne Booster, sammle 50 Elektro-Rennwagen und 50 Fähigkeitskarten, und tritt gegen Gegner an – wer verliert, muss sein eingesetztes Auto abgeben.
