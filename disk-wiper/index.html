🧹 Festplatten-Reiniger

Überschreibt den freien Speicherplatz deiner Festplatte mit Nullen. Kein Browser kann das direkt tun (Webseiten haben keinen Zugriff auf rohen Speicherplatz) – deshalb gibt's hier den fertigen Terminal-Befehl zum Kopieren, für macOS und Linux gleichermaßen.

Bevor du das laufen lässt:
  • Es wird lediglich eine einzige Datei angelegt, die mit Nullen gefüllt wird, bis der Datenträger voll ist – danach wird genau diese Datei wieder gelöscht. Bereits vorhandene Dateien werden nie angefasst, es wird nie direkt auf ein Geräte-/Raw-Device geschrieben.
  • Der Datenträger ist währenddessen kurzzeitig zu 100 % voll – andere offene Programme können in dem Moment Fehler beim Speichern zeigen.
  • Auf SSDs/Flash-Speicher (Standard bei aktuellen Macs) bringt das sicherheitstechnisch kaum etwas: Wear-Leveling und TRIM sorgen ohnehin dafür, dass „freie" Blöcke intern neu verwaltet werden. Apple hat deshalb z. B. „Papierkorb sicher leeren" seit Jahren entfernt. Sinnvoll bleibt der Trick trotzdem, etwa um Backup-Images oder VM-Disks danach besser komprimieren zu können.
  • Je nach freiem Speicherplatz kann der Vorgang lange dauern.

Schnellbefehl (macOS & Linux)

Zum direkten Einfügen ins Terminal – überschreibt den freien Platz auf dem Volume deines Home-Verzeichnisses:

f="$HOME/.wipe_free_space_fill.tmp"; trap 'rm -f "$f"' EXIT INT TERM; dd if=/dev/zero of="$f" bs=1048576 2>/dev/null; rm -f "$f"; echo "Fertig: freier Speicher überschrieben."

Für eine externe Festplatte ersetze $HOME durch den Pfad des Volumes, z. B. /Volumes/MeineDrive (macOS) oder /media/meindrive (Linux). Mit Strg+C kannst du jederzeit sicher abbrechen – die Fülldatei wird dabei automatisch wieder entfernt.

Skript mit Sicherheitsabfrage (empfohlen)

Zeigt vorher freien Speicherplatz und Warnhinweise an und fragt einmal nach, bevor es losgeht:

#!/usr/bin/env bash
set -euo pipefail

TARGET_DIR="${1:-$HOME}"
FILL_FILE="$TARGET_DIR/.wipe_free_space_fill.tmp"

cleanup() { rm -f "$FILL_FILE"; }
trap cleanup EXIT INT TERM

if [ ! -d "$TARGET_DIR" ]; then echo "Verzeichnis nicht gefunden: $TARGET_DIR" >&2; exit 1; fi
if [ ! -w "$TARGET_DIR" ]; then echo "Keine Schreibrechte in: $TARGET_DIR" >&2; exit 1; fi

FREE_KB=$(df -Pk "$TARGET_DIR" | awk 'NR==2 {print $4}')
FREE_GB=$((FREE_KB / 1024 / 1024))
echo "Ziel-Verzeichnis:  $TARGET_DIR"
echo "Freier Speicher:   ca. ${FREE_GB} GB"
echo
read -r -p "Freien Speicher jetzt mit Nullen überschreiben? [y/N] " confirm
case "$confirm" in
  [yY]|[jJ]) ;;
  *) echo "Abgebrochen."; exit 0 ;;
esac

echo "Fülle freien Speicher mit Nullen (Strg+C zum sicheren Abbrechen)..."
dd if=/dev/zero of="$FILL_FILE" bs=1048576 2>/dev/null || true

sync 2>/dev/null || true
echo "Fertig: freier Speicher wurde mit Nullen überschrieben, Fülldatei entfernt."
⬇ wipe_free_space.sh herunterladen

So benutzt du das Skript

  1. Datei speichern, z. B. als wipe_free_space.sh.
  2. Im Terminal ausführbar machen: chmod +x wipe_free_space.sh
  3. Starten: ./wipe_free_space.sh (Systemvolume) oder ./wipe_free_space.sh /Volumes/MeineDrive für eine andere Platte.
  4. Sicherheitsabfrage mit y bestätigen.

Läuft identisch unter macOS und Linux – dd, df und rm sind auf beiden Systemen Standard-Bordmittel.
